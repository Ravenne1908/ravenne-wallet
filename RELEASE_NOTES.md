# Ravenne Wallet v9.11.0 — ghost splash and cleaner menus

## Ghost splash

- The **235-frame GhosttyFetch animation** (MIT) is now the Ravenne boot
  splash. Monochrome, scaled to the window, centered, with a progress bar.
- Any key skips it. Resizing the window re-scales it live.
- **Foreground only**: no background is painted, so a Windows Terminal
  background image stays visible. Light and dark palettes are chosen from the
  detected terminal background (OSC 11).
- Length: **short** (~1.5 s), **normal** (~2.4 s, default), **full** (~4.3 s).
- Controls: **Settings → Wallet & display** (on/off, length, preview, theme),
  `--anim short|normal|full`, `--no-anim`, `RAVENNE_NO_ANIM=1`.
- The frames are embedded gzip+base64 in `assets/ghost.js` (generated by
  `scripts/build-ghost.mjs`), so the splash works in the single-file bundle
  and in `ravenne.exe` with no extra file to ship.
- Attribution: `THIRD_PARTY_NOTICES.md` (GhosttyFetch, MIT; Ghostty logo).

## Interface improvements

- **Icon column**: every menu row now aligns its icon in a dedicated column;
  labels start at the same position even when a row has no icon.
- **Selection without inverse video**: a bold `›` plus underlined label, so the
  selected row does not paint a solid block over a background image.
- **Title bar hint**: the current version sits on the right of the menu frame.
- **Scroll indicators** now show how many entries are hidden
  (`↑ 3 more` / `↓ 2 more`).
- **Synchronized output** (`ESC[?2026h`) on menus and splash: less flicker.
- `banner()` now shows the active chain and profile on the right; `panel()`
  headings are underlined with a rule.

## Known advisory (not a code bug)

`npm audit` reports a critical advisory in `form-data` pulled by
`monero-javascript → request`. There is **no upstream fix**. Ravenne only uses
`monero-javascript` for local WASM key generation; the vulnerable `request` /
`form-data` HTTP path is not used (wallet RPC goes through our own `fetch`).
CI keeps the audit step non-blocking until Monero tooling is replaced or
upstream updates.

## Install

Unzip → run `ravenne.bat` or `ravenne.exe`.
From source: `npm install` then `.\ravenne.bat` (Node.js 18+).
